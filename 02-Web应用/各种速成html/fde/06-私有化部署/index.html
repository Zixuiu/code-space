FDE 速成 · 私有化部署

FDE 速成知识点 · 实战向

金融/政企/医疗客户数据不能出内网。FDE 得把整套（含大模型）部署到客户机房，用 Ollama/vLLM 跑私有模型，数据不出厂。

你会学到

  • 什么时候必须私有化（数据合规）
  • Ollama 跑本地模型
  • vLLM 高并发推理
  • Docker 封装整个服务

核心概念

触发条件：客户要求数据不出网、等保/合规、或对公有云 LLM 不信任。

Ollama：单机本地跑模型，最简单；vLLM：高吞吐、多卡，适合并发大的场景。

接口一致：本地模型同样暴露 OpenAI 格式，LangChain 改 base_url 即可，业务代码不动。

案例可直接参考的代码

# docker-compose.yml 起一个本地 Ollama
# services:
#   ollama:
#     image: ollama/ollama
#     ports: ["11434:11434"]
#     volumes: ["ollama:/root/.ollama"]
# volumes:
#   ollama:

# Python 侧：base_url 指向本地，api_key 随便填
from langchain_openai import ChatOpenAI
llm = ChatOpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama",
    model="qwen2.5:7b",   # 本地已 pull 的模型
)

动手练习

本地装 Ollama，pull qwen2.5:7b，跑通上面这段，验证私有模型回复（完全不联网）。
