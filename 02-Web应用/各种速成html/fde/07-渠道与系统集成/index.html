FDE 速成 · 渠道与系统集成

FDE 速成知识点 · 实战向

接客户系统本质就是「调 API」。官网挂件最简单（fetch 你的 /chat），CRM/ERP 用 Webhook 推事件，后端统一处理。

你会学到

  • 官网聊天挂件（iframe）怎么嵌
  • CRM Webhook 接收与回包
  • 后端统一 /chat 接口的价值
  • 把客户业务 API 封装成 Agent 工具

核心概念

官网挂件：前端嵌个 iframe 直接 fetch 你的 /chat，和 langchain_web.html 一样。

CRM 集成：客户系统用 Webhook/OpenAPI 推对话事件，你回 JSON，客户再渲染到自己 UI。

统一后端：所有渠道都调同一个 /chat，多租户隔离在后端做，前端只管展示。

案例可直接参考的代码

<!-- 前端：官网聊天挂件 -->
<iframe src="https://你的服务/chat-widget"
        style="position:fixed;right:20px;bottom:20px;width:380px;height:600px;border:0">
</iframe>

# 后端：CRM Webhook 接收并回包
from flask import Flask, request, jsonify
app = Flask(__name__)

@app.route("/webhook/crm", methods=["POST"])
def crm_webhook():
    data = request.json
    uid = data["customer_id"]
    msg = data["message"]
    return jsonify({"reply": chat(uid, msg)})  # chat 见多租户章节
