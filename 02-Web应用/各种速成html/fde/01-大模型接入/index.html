FDE 速成 · 大模型接入

FDE 速成知识点 · 实战向

把任意大模型（OpenAI / DeepSeek / 通义 / 本地）接进应用，是 FDE 的地基。统一用 LangChain 的 ChatOpenAI 接口，换个 base_url 和 model 就能切厂商。

你会学到

  • 用 ChatOpenAI 统一接各家模型
  • OpenRouter 聚合网关的用法（一个 Key 调多家）
  • API Key 与 .env 安全管理
  • 模型选型与成本意识

核心概念

统一接口：LangChain 的 ChatOpenAI 本质是个 OpenAI 兼容客户端，只要目标服务暴露 OpenAI 格式接口，改 base_url 即可，不用换代码。

OpenRouter：一个 Key 聚合几百个模型（含免费档），适合 FDE 多模型对比、快速验证。

安全：Key 永远放 .env，别写进前端/提交仓库；免费模型质量弱，生产换付费档。

注意：给 OpenRouter 传自定义 HTTP 头（如 X-Title）必须 ASCII，中文会触发 ascii 编码错误导致调用失败。

案例可直接参考的代码

import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()
llm = ChatOpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key=os.getenv("OPENROUTER_API_KEY"),
    model=os.getenv("OPENROUTER_MODEL", "openrouter/free"),
    temperature=0.7,
)
print(llm.invoke("用一句话介绍你自己").content)
