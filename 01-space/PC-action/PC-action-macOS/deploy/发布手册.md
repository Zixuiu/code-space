## 二、干净机全流程冒烟剧本（8 项）

1. 全新 Windows 机（或虚拟机），安装 `dist\PC-Action.exe` / `PC-Action-Setup-1.0.0.exe`
2. 启动 → 弹出**登录窗**（未登录不应直接进入主界面）
3. 点注册 → 看到**协议勾选框**（未勾选无法注册）
4. 注册成功 → 收到验证码邮件 → 登录 → 主界面图标/布局正常
5. 试用期内：核心功能（录制/回放/组合技）可用
6. 把系统日期 +10 天 → 重启 → 提示**试用过期**，弹激活对话框，核心功能被拦截
7. 点「去购买」→ 打开 `http://1c4af4eb.r8.cpolar.top` 支付页 → 扫码付款
8. 后台确认收款 → 收到激活码邮件 → 输入激活码 → VIP 开通，功能恢复

## 三、杀软误报预案

**现象**：Windows Defender / 360 / 火绒可能提示「未知发布者」「疑似病毒」。

**原因**：exe 用 PyInstaller 打包，未购买代码签名证书（约 ¥800+/年）。

**应对话术（给用户看）**：
- 这是误报，软件不含任何恶意行为
- 在拦截弹窗选「仍要运行」/「允许」
- 或把 `PC-Action.exe` 加入杀软白名单
- 激活码与全部功能不受影响

**进阶（可选，发布后做）**：
- 购买代码签名证书（DigiCert /  Sectigo EV），重打包后误报基本消失
- 提交 Microsoft SmartScreen 信誉申诉

## 四、SMTP 授权码配置（拿到后填）

### PC-Action 注册验证码（`.env`，放 exe 同目录）
```
SENDER_EMAIL=your-qq@qq.com   # ← 改成你真实QQ邮箱（发件箱）
SENDER_PASSWORD=<QQ邮箱授权码，不是登录密码>
```
QQ 邮箱授权码获取：QQ邮箱 → 设置 → 账户 → 开启 IMAP/SMTP → 生成授权码

### PayPro 发码邮件（`config/application-prod.yml` 末尾 spring.mail 段）
```yaml
spring:
  mail:
    host: smtp.qq.com
    port: 587
    username: your-qq@qq.com   # ← 改成你真实QQ邮箱（与上面 SENDER_EMAIL 一致）
    password: <QQ邮箱授权码>
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
```

## 五、人工收款兜底 SOP（PayPro 起不来时）

若发布当天 PayPro 服务异常，仍可收款：

1. 用户通过微信/支付宝直接转账 ¥99 给你
2. 你从 `activation_codes` 表挑一个 `used=0` 的码（或 `qr` 目录同款）
3. 手动发码给用户 → 用户 PC-Action「会员与激活」输入开通
4. 激活对话框已内置「购买渠道即将开放，可联系客服」文案，不会暴露支付页故障

## 六、发布后运维

- **cpolar 不能关**：隧道进程挂着 = 支付页在线；关机/睡眠 = 买家付不了
- **域名随机**：免费版重启隧道域名会变，需重打包 exe 烧入新链接；建议升 9 元/月固定域名套餐
- **激活码补货**：库存低于 10 个时，跑 `PayPro-src/tools/gen_codes.py` 再生成一批
- **监控**：每天看一眼 `activation_codes` 表的 used 数量与 PayPro 后台订单
