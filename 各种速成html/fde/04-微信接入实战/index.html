FDE 速成 · 微信接入实战

FDE 速成知识点 · 实战向

客户要接公众号/企业微信？核心是「被动回调」：微信推消息到你服务器 → 你调大模型 → 回给微信。三个硬门槛必须讲清。

你会学到

  • 微信回调校验（SHA1 签名）
  • 消息加解密
  • 5 秒响应限制 → 客服消息异步回
  • 公网服务器 + 域名 + HTTPS 前置条件

核心概念

被动回调：微信服务器主动 POST 用户消息到你的回调 URL，你必须在 5 秒内响应，否则用户收不到回复。

异步回包：大模型常超 5 秒，标准做法是先立刻回「正在查询…」，后台算完用「客服消息接口」主动推第二条。

前置条件：你的服务必须公网可达（本地 127.0.0.1 不行），配 token 校验 + 消息加解密。

案例可直接参考的代码

from flask import Flask, request
import hashlib

app = Flask(__name__)
TOKEN = "你的公众号Token"

@app.route("/wechat", methods=["GET"])
def verify():
    sig = request.args.get("signature")
    ts, nonce, echostr = request.args.get("timestamp"), request.args.get("nonce"), request.args.get("echostr")
    tmp = sorted([TOKEN, ts, nonce])
    if hashlib.sha1("".join(tmp).encode()).hexdigest() == sig:
        return echostr
    return "fail", 403

# POST 分支：接收用户消息 -> 调大模型 -> 异步回（此处省略消息体解析与客服消息接口）
if __name__ == "__main__":
    app.run(port=80)

把服务部署到云服务器 + 域名，在公众号后台填回调 URL 与 Token，跑通 GET 校验。
