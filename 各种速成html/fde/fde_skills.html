FDE 全栈能力地图

维度 01 · 地基

AI 与大模型基础

不懂模型就别谈部署。这一层是和任何算法/研发对话的语言。

  • 必会LLM 工作原理token、注意力机制、上下文窗口、训练/推理区别
  • 必会主流模型谱系GPT / Claude / Llama / DeepSeek / Qwen / Gemini 的定位与取舍
  • 核心Prompt 工程Few-shot、链式提示、结构化输出、角色设定已实操
  • 核心推理参数调优temperature / top_p / max_tokens 对效果的影响已实操
  • 核心模型选型与成本管理按场景选模型、按 token 计价、免费档 vs 付费档已实操
  • 进阶幻觉识别与缓解不确定性表达、引用溯源、事实核查
  • 进阶评测方法基准测试 / 人工评估 / LLM-as-judge
维度 02 · 引擎

Agent 与编排

FDE 的核心引擎。把「会聊天」升级成「能干活」。

  • 核心Agent 范式ReAct / Plan-Execute / Reflexion 的适用场景已实操
  • 核心LangChain / LlamaIndex主流编排框架，把组件拼成可运行链路已实操
  • 核心Memory 管理Buffer / Summary / Vector 短期长期记忆已实操
  • 核心Tool / Function Calling把外部能力封装成模型可调用函数已实操
  • 进阶多 Agent 协作CrewAI / AutoGen、角色分工与消息传递
  • 进阶工作流编排DAG / 状态机 / 人工介入 Human-in-loop
  • 进阶思考链可观测verbose / tracing / LangSmith 调试已实操
维度 03 · 记忆

RAG 与知识工程

让 AI 懂客户业务。知识一多，纯 prompt 就不够了。

  • 核心文档解析与清洗PDF / 网页 / 数据库 / 表格抽取
  • 核心切分策略固定 / 语义 / 递归切分对不同文档的效果
  • 核心向量库Chroma / FAISS / Milvus / pgvector 选型
  • 进阶检索增强Hybrid Search / Rerank / Query Rewrite
  • 进阶知识库更新与版本增量索引、过期淘汰、灰度
  • 进阶GraphRAG / 知识图谱复杂关系型知识的检索
  • 必会私有数据接入合规敏感数据如何进向量库不出网已实操
维度 04 · 本职

前端与交付层

「前端」部署工程师的本职：让客户看得见、用得上。

  • 必会HTML/CSS/JS 与框架React / Vue 至少熟一门，能快速搭界面
  • 核心对话 UI / 聊天组件消息流、流式渲染、思考过程展示已实操
  • 核心嵌入集成iframe / Web Component / SDK 三种嵌入方式已实操
  • 核心实时通信WebSocket / SSE / 流式输出（大模型必用）
  • 进阶回调与事件处理微信/CRM 回调、消息加解密、异步回包已实操
  • 进阶低代码 / 无代码平台用金蝶等 PaaS 加速交付，少写代码
  • 进阶多端适配PC / 移动 / 小程序一套逻辑多端复用
维度 05 · 服务

后端与服务化

把对话引擎包成一个统一 API，所有渠道来调它。

  • 必会API 设计REST / WebSocket / GraphQL 接口契约
  • 必会服务框架FastAPI / Flask / Node 至少一门已实操
  • 核心多租户隔离按 user_id / session 分桶 Memory，绝不串台
  • 核心鉴权与密钥管理OAuth / API Key / 密钥轮换，前端不暴露 Key已实操
  • 核心限流与并发控制防刷、控成本、保护后端与模型额度
  • 进阶异步任务大模型超时处理、后台计算、5 秒响应限制
  • 进阶可观测性日志 / metrics / tracing 串联全链路
维度 06 · 工程

部署与私有化

从「能跑」到「敢给客户用」的分水岭。

  • 核心容器化Docker / Compose 把环境打包可复现
  • 进阶编排K8s / 云厂商托管，弹性伸缩
  • 进阶私有化推理vLLM / Ollama / TGI / SGLang 跑客户内网模型已实操
  • 进阶GPU 与推理优化量化 / 批处理 / KV Cache 降本提速
  • 核心监控告警Prometheus / Grafana 盯延迟与错误率
  • 进阶灰度与回滚模型/版本渐进发布，出错能秒回退
维度 07 · 接入

渠道与系统集成

接进客户系统才是 FDE 的现场价值。前面聊过这套架构。

  • 核心微信生态公众号 / 企业微信 / 小程序回调与加密已实操
  • 核心官网嵌入聊天挂件，与 live 版前端一致已实操
  • 核心CRM / ERP 集成销售易 / 金蝶 / Salesforce 的 Webhook / OpenAPI已实操
  • 进阶工单 / 邮件系统把对话事件沉淀为客户服务闭环
  • 进阶协作平台钉钉 / 飞书 / Slack / Teams 机器人
  • 进阶业务 API 封装为 Tool查订单/库存变成 Agent 真能调的工具
  • 战略单点登录 / 组织架构对接客户 IAM，按部门/角色授权
维度 08 · 软硬

业务理解与软技能

最值钱的一层。买 AI ≠ AI 转型，落地才是瓶颈。

  • 核心需求抽象把客户模糊诉求翻译成 Agent 工具与流程
  • 进阶行业认知金融 / 医疗 / 制造 / 零售 / 政企的差异化
  • 核心售前方案与现场 Demo用客户的语言讲架构、当场出效果已实操
  • 战略驻场沟通与客户信任贴身服务、管理预期、成为不可替代的人
  • 进阶项目交付节奏把 PoC 推成生产、控制范围 creep
  • 战略价值量化ROI / 效率提升，让客户持续买单
  • 进阶跨团队协同拉着研发 / 产品 / 销售一起交付
维度 09 · 红线

安全与合规

政企/金融客户的第一道门槛，踩不得。

  • 核心数据不出网 / 私有化敏感行业必须内网闭环
  • 核心内容安全审核输入/输出过滤，防越狱与违规已实操
  • 进阶权限与数据脱敏按角色隔离、PII 自动遮蔽
  • 进阶审计留痕会话存档，金融/医疗常要求合规追溯
  • 战略模型与供应链安全开源模型来源、依赖漏洞管理
  • 战略合规框架等保 / 数据安全法 / 行业监管对接
没有匹配的能力点，换个关键词试试。

三阶段成长路线

从今天的位置，到能独立交付客户，建议按这三阶推进。你现在在第一阶。
1

技术底座 · 你在这

LangChain Agent + 真模型接入 + 工具调用 + 渠道架构认知。我们已经用 langchain/ 项目亲手跑通这一层，约命中 12 项能力。

2

工程化

多租户隔离、鉴权限流、Docker/K8s 容器化、私有化推理（vLLM/Ollama）、监控告警。把 Demo 变成生产级服务。

3

业务落地

驻场贴身、需求抽象成工具、行业认知、价值量化、合规闭环。让 AI 在客户现场真被用起来——这才是 FDE 真正值钱的地方。
